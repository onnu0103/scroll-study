よくある質問

どんなアプリですか？

宅建・FP2級・簿記・ITパスポート・基本情報技術者・TOEIC・英検・漢検・心理学・行動経済学・統計学・ 哲学倫理学・法学・経済学・Python の15分野について、 4択問題・一問一答・よくある誤解・解説・会話形式のポストが、タイムラインに流れてくる学習アプリです。 スクロールして読み、答えて、気になったものを保存していくだけで学習が進みます。

お金はかかりますか？

無料です。アプリ内課金も広告もありません。

通信できないところでも使えますか？

使えます。問題や解説はすべてアプリの中に入っているので、機内モードや地下鉄でも読めます。 学習の記録の同期だけ、通信が戻ったときにまとめて行われます。

アカウントの登録は必要ですか？

いいえ。メールアドレスもパスワードも要りません。 アプリが自動で作る匿名の利用者IDで、学習の記録を保存します。

iPhoneを買い替えても記録は引き継げますか？

匿名の利用者IDは端末ごとに作られるため、アプリを削除したり機種を変えたりすると、 前の記録には戻れません。大切な記録は、保存したポストを共有ボタンでメモアプリなどに残しておいてください。

学習の内容はいつの情報ですか？

分野ごとに基準の時点を決めて作っています。アプリの各項目の「細目の地図」を開くと、 その分野がどの時点の情報にもとづいているかと、参考にした出典の一覧が見られます。 法令・試験の形式・税制・統計は変わりますので、 大事なことは必ず試験の実施団体や官公庁の公式の発表を確認してください。

内容にまちがいを見つけました

上のメールアドレスまでご連絡ください。どの分野・どの問題かと、正しい内容の出典を教えていただけると助かります。 確認のうえ、アプリの更新で直します。

毎日の通知が届きません

iPhoneの「設定」→「スクロール学習」→「通知」で、通知が許可されているか確認してください。 許可されていれば、アプリの「学ぶ項目」画面で「毎日のリマインド」をオンにし、時刻を選んでください。 この通知はiPhoneの中だけで鳴るもので、運営者からは何も送っていません。

文字が小さくて読みにくいです

アプリの「学ぶ項目」画面の「文字の大きさ」で、小・標準・大・特大から選べます。 はじめは、iPhoneの「設定」→「画面表示と明るさ」→「テキストサイズ」に合わせています。

データを全部消したいです

アプリの「学ぶ項目」画面を下までスクロールし、 「アカウントとデータを削除する」を押してください（確認のため2回押します）。 端末とサーバーの両方から、学習の記録・用語集・いいね・ブックマーク・自分のポストがすべて消えます。 元に戻すことはできません。

プライバシーポリシー

運営者（秋元挑）は、本アプリでお預かりする情報を次のように扱います。

1. 集める情報

本アプリは、氏名・メールアドレス・電話番号・住所・生年月日などの、 あなたを直接特定する情報を集めません。アカウントの作成に、メールアドレスやパスワードは要りません。

保存するのは、次の学習の記録だけです。

  • 選んだ学ぶ項目と、その設定
  • クイズと一問一答の成績、苦手リスト、どの細目を学んだかの記録
  • 用語集にたまった用語
  • いいね・ブックマークしたポスト
  • 自分で書いたポストと、ポストに残したメモ
  • 文字の大きさなど、アプリの設定

また、あなたの端末を見分けるために、本アプリが自動で作る匿名の利用者ID（ランダムな文字列）を使います。 このIDから、あなたが誰かはわかりません。

2. 使う目的

学習の記録を保存し、次に開いたときに続きから使えるようにするためだけに使います。 広告の配信や、利用状況を分析する外部のツールには使っていません（そうしたツールを入れていません）。

3. 保存する場所と、外部への委託

学習の記録と匿名の利用者IDは、米国の Google LLC が提供するクラウドサービス 「Firebase」（Firebase Authentication と Cloud Firestore）に保存します。 そのため、情報は日本国外のサーバーで取り扱われることがあります。 Google LLC は運営者の委託先であり、Googleのプライバシーポリシーにしたがって取り扱われます。

保存した記録は、その利用者ID本人以外は読み書きできないように設定しています。運営者も個別の内容は見ません。

4. 第三者への提供

上の委託を除き、あなたの情報を第三者に提供・販売することはありません。 法令にもとづく開示の求めがあった場合を除きます。

5. 通知について

毎日のリマインド通知は、あなたのiPhoneの中だけで設定され、運営者やサーバーには送られません。 本アプリはプッシュ通知（運営者から送る通知）を使いません。

6. 外部サイトへのリンク

出典のリンクを押すと、Safariで外部のサイトが開きます。 リンク先での情報の扱いは、そのサイトの方針にしたがいます。

7. 削除のしかた

アプリの「学ぶ項目」画面の「アカウントとデータを削除する」から、 いつでも、端末とサーバーの両方の記録をすべて消せます。 削除すると匿名の利用者IDも消え、元に戻すことはできません。

8. 子どもの利用について

本アプリは、あなたを特定する情報を集めません。年齢にかかわらず、同じ扱いをします。

9. この方針の変更

内容を変えるときは、本アプリとサポートページの記載を新しくします。
